#🛒 E-Commerce Full Stack Application
A fully functional e-commerce web application built using the MERN stack (MongoDB, Express.js, React, Node.js). This project features both frontend and backend components, including user authentication, product browsing, shopping cart, and admin management tools.

🚀 Features
Frontend (React + Vite)
Responsive UI using Bootstrap and Material UI

Product listing, filtering, and searching

User authentication (login/register)

Cart and checkout flow

Order history

Backend (Node.js + Express)
RESTful API with JWT-based authentication

MongoDB for storing users, products, and orders

Role-based access (Admin/User)

Order and product management (CRUD)

Payment integration-ready structure

🛠️ Tech Stack
Frontend: React, React Router, Axios, Bootstrap, Material UI

Backend: Node.js, Express.js, MongoDB, Mongoose

Auth: JSON Web Token (JWT), bcrypt

Dev Tools: Vite, Nodemon, Postman
